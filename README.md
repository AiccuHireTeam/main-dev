# main-dev
Development repository for all Aiccuhire Platform

## Run UI Locally

**Prerequisites:** Node.js (v24+) and `pnpm`

```bash
cd ui
./start.sh
```
*(Or run `pnpm start` / `pnpm dev` inside the `ui/` directory. The startup script automatically installs dependencies and removes Replit-only platform exclusions if needed.)*

### Local URLs
- **Dashboard UI:** http://localhost:3000
- **API Server:** http://localhost:5005
- **Mockup Sandbox:** http://localhost:5001
